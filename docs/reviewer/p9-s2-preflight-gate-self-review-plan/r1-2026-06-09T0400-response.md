References: `docs/plans/2026-06-09-P9.S2-preflight-gate-self-review.md:526`, `docs/plans/2026-06-09-P9.S2-preflight-gate-self-review.md:532`, `docs/plans/2026-06-09-P9.S2-preflight-gate-self-review.md:629`, `skills/external-review/scripts/external-reviewer.py:722`.
After the subcommand is added, these tests will fail in `repo_root()` instead of validating clean/failing preflight behavior. Make `_repo()` initialize a git repo, matching the existing review subprocess harness, or explicitly change the implementation to allow non-git cwd for standalone `preflight`.

F2. Severity: important. The plan does not cover the spec’s requirement that each deterministic check class be exercised through the standalone `preflight` subcommand.
References: `docs/specs/2026-06-09-P9.S2-preflight-gate-self-review-design.md:231`, `docs/specs/2026-06-09-P9.S2-preflight-gate-self-review-design.md:234`, `docs/plans/2026-06-09-P9.S2-preflight-gate-self-review.md:539`.

Task 2 only covers clean, generic failure, JSON shape, and warning-only. Add focused subprocess tests for the missing context and oversized context cases at minimum, and preferably one test per listed check class.

F3. Severity: important. The plan omits the schema-too-new ordering regression test required by the spec.
References: `docs/specs/2026-06-09-P9.S2-preflight-gate-self-review-design.md:265`, `docs/specs/2026-06-09-P9.S2-preflight-gate-self-review-design.md:268`, `docs/plans/2026-06-09-P9.S2-preflight-gate-self-review.md:690`.

Task 3 covers preflight refusal, `--no-preflight`, clean round 1, round 2 skip, and missing context exit 2, but not this ordering. Add a subprocess test that creates a chain with `chain.json` schema_version above supported and a target that would otherwise fail preflight, then asserts the schema error path wins.
