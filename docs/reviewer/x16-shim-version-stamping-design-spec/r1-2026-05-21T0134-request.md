   90	### 3. Shared runtime check fragment
   91	
   92	A template fragment lives at `scripts/lib/shim-version-check.sh`:
   93	
   94	```bash
   95	# Embedded into every generated Superstar shim.
   96	# Hard-exits only if BOTH source VERSION and stamped shim version are readable
   97	# AND they differ. Missing/unreadable VERSION is treated as 'cannot compare' and
   98	# the shim execs normally (existing path-resolution errors handle the broken
   99	# case more loudly than a spurious version warning would).
  100	__superstar_check_version() {
  101	    local shim_version="$1"
  102	    local shim_name="$2"
  103	    local source_root="$3"
  104	    local installer="$4"
  105	
  106	    local version_file="$source_root/VERSION"
  107	    [[ -r "$version_file" ]] || return 0
  108	    local src_version
  109	    src_version="$(head -n1 "$version_file" 2>/dev/null | tr -d '[:space:]')"
  110	    [[ -n "$src_version" && -n "$shim_version" ]] || return 0
  111	
  112	    if [[ "$src_version" != "$shim_version" ]]; then
  113	        printf 'ERROR: %s shim is %s but Superstar source is %s\n' \
  114	            "$shim_name" "$shim_version" "$src_version" >&2
  115	        printf 'Re-run: bash %s/%s\n' "$source_root" "$installer" >&2
  116	        exit 1
  117	    fi
  118	}
  119	```
  120	
  121	Each installer reads this fragment and inlines it into the generated shim. The shim header values are passed as arguments to `__superstar_check_version` so the fragment itself contains no installer-specific values — one source of truth, three identical embeddings.

  145	### 4. Strict failure semantics
  146	
  147	A shim hard-exits (status 1, no `exec`) **if and only if** all three hold:
  148	
  149	1. `$SOURCE_ROOT/VERSION` is readable.
  150	2. The stamped `shim-version` value is non-empty.
  151	3. The two values differ after whitespace-trim.
  152	
  153	Any other state — VERSION missing, VERSION empty, stamped value missing — and the shim execs as normal. The existing path-resolution errors (source script not found, etc.) are louder and more diagnostic than a half-informed version warning.

  183	### 6. `tasktool` ↔ pre-commit hook handshake
  184	
  185	Hook template `tools/tasktool/templates/pre-commit-tasktool` gains a stamped header block at install time. `tools/tasktool/install.sh --hook` interpolates the values, the same shape as a shim header but using `superstar-hook-*` keys to make the failure message obvious:
  186	
  187	```bash
  188	#!/usr/bin/env bash
  189	# superstar-hook
  190	# superstar-hook-name: tasktool-pre-commit
  191	# superstar-hook-version: 6.3.2
  192	# superstar-hook-source-root: $HOME/Dev/sigreer/skills/superstar
  193	# superstar-hook-installer: tools/tasktool/install.sh --hook
  194	# superstar-hook-generated-at: 2026-05-21T14:23:07Z
  195	```
  196	
  197	The Python `tasktool` entrypoint adds a startup check:
  198	
  199	1. `git rev-parse --show-toplevel` — if not in a git repo, skip silently.
  200	2. `<repo>/.git/hooks/pre-commit` exists? If not, skip silently.
  201	3. Read first 16 lines, look for `superstar-hook-name: tasktool-pre-commit`. If not present, skip silently — the file is some other hook the user maintains.
  202	4. Extract `superstar-hook-version` and `superstar-hook-source-root`.
  203	5. Read `$source_root/VERSION`. If unreadable, skip silently.
  204	6. Compare. If they differ, hard-exit before doing any tasktool work:
  205	
  206	```
  207	ERROR: tasktool pre-commit hook is 6.3.1 but Superstar source is 6.3.2
  208	Hook: /home/simon/Dev/sigreer/multistore/.git/hooks/pre-commit
  209	Re-run: bash /home/simon/Dev/sigreer/skills/superstar/tools/tasktool/install.sh --hook --force
  210	```
  211	
  212	The re-run path is reconstructed from the stamped `superstar-hook-source-root` so the user can copy-paste it directly. If the stamped source root no longer exists on disk, fall back to printing the relative installer path (`tools/tasktool/install.sh --hook --force`) and a one-line note that the source root must be located first.
  213	
  214	The repo path naming in the message is deliberate — unlike the three global shims, this is repo-local state and the user needs to know which repo to act on.
  215	
  216	Cost budget: a couple of `subprocess.run("git rev-parse", check=False)`, two `Path.exists()` calls, and a short `read_text().splitlines()[:16]`. Negligible compared to existing tasktool startup.
  217	
  218	The check runs on **every** tasktool invocation (silent unless drift is real). Discovering stale hook state when the user is already thinking about tasktool beats discovering it later during a commit. If a future subcommand needs to operate explicitly outside a repo, the check is already a no-op there because step 1 short-circuits.

  323	## Risks and mitigations
  324	
  325	- **`bump-version.sh` errors on `VERSION` missing.** Mitigation: when `--check` runs against an old checkout that predates this work (no VERSION file, no entry in `.version-bump.json`), the existing `MISSING` row handles it gracefully. No code change needed beyond the new `format: plain` dispatch.
  326	- **`scripts/lib/shim-version-check.sh` evolves and shims silently embed an old version of the check fragment.** Mitigation: this is exactly what the version check is for — the fragment lives inside the shim, but the shim's `version` stamp is bumped any time the fragment changes (since the fragment lives in the source tree and is touched by version-bumped releases). A bumped VERSION forces a `deploy.sh` which re-stamps every shim.
  327	- **Existing per-repo `~/.local/bin/reviewer-agent` was hand-edited by the user.** Mitigation: `install-reviewer-agent.sh` refuses to overwrite without `--force` if the existing file lacks the `superstar-shim` marker (mirroring how `external-reviewer/install.sh` and `tasktool/install.sh` behave today). The user is told to inspect, then re-run with `--force`. `deploy.sh` always passes `--force`, so a deploy after this work lands wipes the old copy intentionally.
  328	- **Tasktool startup cost.** Mitigation: the hook check skips inside <1ms when the hook is absent or unmarked (which is the common case — only repos that opted into the hook see the full check). The full check is still cheap: two filesystem stats and a short read. Below tasktool's existing JSON-load cost.
  329	- **Out-of-tree shims (other users, other projects).** Mitigation: not in scope. The shim header convention is unique to Superstar (`superstar-shim` magic comment) and won't collide with other tooling. Other projects' shims under `~/.local/bin/` are untouched by `deploy.sh --check` because the scan keys on the `superstar-shim` magic line.

  331	## Acceptance criteria
  332	
  333	1. `VERSION` exists at repo root and is the only file consulted by shims at runtime.

    1	#!/usr/bin/env bash
    2	#
    3	# bump-version.sh — bump version numbers across all declared files,
    4	# with drift detection and repo-wide audit for missed files.
    5	#
    6	# Usage:
    7	#   bump-version.sh <new-version>   Bump all declared files to new version
    8	#   bump-version.sh --check         Report current versions (detect drift)
    9	#   bump-version.sh --audit         Check + grep repo for old version strings
   10	#
   11	set -euo pipefail
   12	
   13	SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
   14	REPO_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"
   15	CONFIG="$REPO_ROOT/.version-bump.json"
   16	
   17	if [[ ! -f "$CONFIG" ]]; then
   18	  echo "error: .version-bump.json not found at $CONFIG" >&2
   19	  exit 1

   22	# --- helpers ---
   23	
   24	# Read a dotted field path from a JSON file.
   25	# Handles both simple ("version") and nested ("plugins.0.version") paths.
   26	read_json_field() {
   27	  local file="$1" field="$2"
   28	  # Convert dot-path to jq path: "plugins.0.version" -> .plugins[0].version
   29	  local jq_path
   30	  jq_path=$(echo "$field" | sed -E 's/\.([0-9]+)/[\1]/g' | sed 's/^/./' | sed 's/\.\././g')
   31	  jq -r "$jq_path" "$file"
   32	}
   33	
   34	# Write a dotted field path in a JSON file, preserving formatting.
   35	write_json_field() {
   36	  local file="$1" field="$2" value="$3"
   37	  local jq_path
   38	  jq_path=$(echo "$field" | sed -E 's/\.([0-9]+)/[\1]/g' | sed 's/^/./' | sed 's/\.\././g')
   39	  local tmp="${file}.tmp"
   40	  jq "$jq_path = \"$value\"" "$file" > "$tmp" && mv "$tmp" "$file"
   41	}
   42	
   43	# Read the list of declared files from config.
   44	# Outputs lines of "path<TAB>field"
   45	declared_files() {
   46	  jq -r '.files[] | "\(.path)\t\(.field)"' "$CONFIG"
   47	}
   48	
   49	# Read the audit exclude patterns from config.
   50	audit_excludes() {
   51	  jq -r '.audit.exclude[]' "$CONFIG" 2>/dev/null
   52	}

   54	# --- commands ---
   55	
   56	cmd_check() {
   57	  local has_drift=0
   58	  local versions=()
   59	
   60	  echo "Version check:"
   61	  echo ""
   62	
   63	  while IFS=$'\t' read -r path field; do
   64	    local fullpath="$REPO_ROOT/$path"
   65	    if [[ ! -f "$fullpath" ]]; then
   66	      printf "  %-45s  MISSING\n" "$path ($field)"
   67	      has_drift=1
   68	      continue
   69	    fi
   70	    local ver
   71	    ver=$(read_json_field "$fullpath" "$field")
   72	    printf "  %-45s  %s\n" "$path ($field)" "$ver"
   73	    versions+=("$ver")
   74	  done < <(declared_files)
   75	
   76	  echo ""
   77	
   78	  # Check if all versions match
   79	  local unique
   80	  unique=$(printf '%s\n' "${versions[@]}" | sort -u | wc -l | tr -d ' ')
   81	  if [[ "$unique" -gt 1 ]]; then
   82	    echo "DRIFT DETECTED — versions are not in sync:"
   83	    printf '%s\n' "${versions[@]}" | sort | uniq -c | sort -rn | while read -r count ver; do
   84	      echo "  $ver ($count files)"
   85	    done
   86	    has_drift=1
   87	  else
   88	    echo "All declared files are in sync at ${versions[0]}"
   89	  fi
   90	
   91	  return $has_drift
   92	}

   94	cmd_audit() {

   98	
   99	  # Determine the current version (most common across declared files)

  152	      fi

  154	    fi

  156	
  157	  if [[ "$found_undeclared" -eq 0 ]]; then
  158	    echo "No undeclared files contain the version string. All clear."
  159	  else
  160	    echo ""
  161	    echo "Review the above files — if they should be bumped, add them to .version-bump.json"
  162	    echo "If they should be skipped, add them to the audit.exclude list."
  163	  fi
  164	}

  191	  echo "Done. Running audit to check for missed files..."
  192	  echo ""
  193	  cmd_audit
  194	}

   20	      exit 1
   21	    fi
   22	  fi

   24	  echo "Installed $HOOK_DEST"

   30	PKG_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"   # → tools/

   36	exec python3 -m tasktool \"\$@\""

   41	  current="$(cat "$TARGET")"
   42	  if [[ "$current" == "$EXPECTED_SHIM" ]] || grep -q "tasktool shim" "$TARGET" 2>/dev/null; then
   43	    echo "tasktool shim already installed (matches). Updating PYTHONPATH note..."
   44	  else
   45	    echo "ERROR: $TARGET exists and is not a tasktool shim. Re-run with --force to overwrite." >&2
   46	    exit 1
   47	  fi
   48	fi

   51	#!/usr/bin/env bash
   52	# tasktool shim — generated by tasktool/install.sh
   53	export PYTHONPATH="${PKG_ROOT}\${PYTHONPATH:+:\$PYTHONPATH}"
   54	exec python3 -m tasktool "\$@"

   57	
   58	echo "Installed $TARGET"
   59	echo "Pointing at $PKG_ROOT/tasktool"

### scripts/publish-to-local-codex.sh

    1	#!/usr/bin/env bash
    2	#
    3	# Publish the repo-local Superstar marketplace payload into Codex's local cache.
    4	#
    5	# Codex's local marketplace installer currently does not materialize symlinked
    6	# payload directories reliably. This wrapper installs the plugin, then copies the
    7	# local wrapper payload with symlinks followed so the versioned cache contains
    8	# real skills, hooks, tools, and assets for new Codex sessions.
    9	
   10	set -euo pipefail
   11	
   12	SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
   13	REPO_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"
   14	
   15	MARKETPLACE="superstar-dev"
   16	PLUGIN="superstar"
   17	DRY_RUN=0
   18	SKIP_CODEX_ADD=0
   19	CACHE_ROOT="${CODEX_HOME:-$HOME/.codex}/plugins/cache"
   20	
   21	usage() {
   22	  cat <<'EOF'
   23	Usage: scripts/publish-to-local-codex.sh [options]
   24	
   25	Options:
   26	  --marketplace NAME   Marketplace name (default: superstar-dev)
   27	  --plugin NAME        Plugin name (default: superstar)
   28	  --cache-root PATH    Codex plugin cache root (default: $CODEX_HOME/plugins/cache or ~/.codex/plugins/cache)
   29	  --skip-codex-add     Skip `codex plugin add`; only materialize and verify cache
   30	  -n, --dry-run        Print actions without writing
   31	  -h, --help           Show this help
   32	
   33	Publishes plugins/superstar into:
   34	  <cache-root>/<marketplace>/<plugin>/<version>/
   35	  <cache-root>/<marketplace>/<plugin>/current/
   36	
   37	The script follows symlinks so cache/<version> and cache/current contain real
   38	directories/files.
   39	EOF
   40	}
   41	
   42	while [[ $# -gt 0 ]]; do
   43	  case "$1" in
   44	    --marketplace) MARKETPLACE="$2"; shift 2 ;;
   45	    --plugin) PLUGIN="$2"; shift 2 ;;
   46	    --cache-root) CACHE_ROOT="$2"; shift 2 ;;
   47	    --skip-codex-add) SKIP_CODEX_ADD=1; shift ;;
   48	    -n|--dry-run) DRY_RUN=1; shift ;;
   49	    -h|--help) usage; exit 0 ;;
   50	    *) echo "Unknown arg: $1" >&2; usage >&2; exit 2 ;;
   51	  esac
   52	done
   53	
   54	SOURCE="$REPO_ROOT/plugins/$PLUGIN"
   55	MANIFEST="$SOURCE/.codex-plugin/plugin.json"
   56	
   57	[[ -d "$SOURCE" ]] || { echo "ERROR: source plugin not found: $SOURCE" >&2; exit 1; }
   58	[[ -f "$MANIFEST" ]] || { echo "ERROR: source manifest not found: $MANIFEST" >&2; exit 1; }
   59	
   60	VERSION="$(
   61	  python3 - "$MANIFEST" <<'PY'
   62	import json
   63	import sys
   64	with open(sys.argv[1], encoding="utf-8") as f:
   65	    print(json.load(f)["version"])
   66	PY
   67	)"
   68	
   69	PLUGIN_CACHE_ROOT="$CACHE_ROOT/$MARKETPLACE/$PLUGIN"
   70	CACHE_DIR="$PLUGIN_CACHE_ROOT/$VERSION"
   71	CURRENT_DIR="$PLUGIN_CACHE_ROOT/current"
   72	
   73	run() {
   74	  if [[ "$DRY_RUN" -eq 1 ]]; then
   75	    printf '+ %q' "$@"
   76	    printf '\n'
   77	  else
   78	    "$@"
   79	  fi
   80	}
   81	
   82	echo "Publishing $PLUGIN@$MARKETPLACE version $VERSION"
   83	echo "Source: $SOURCE"
   84	echo "Cache:  $CACHE_DIR"
   85	echo "Current: $CURRENT_DIR"
   86	
   87	if [[ "$SKIP_CODEX_ADD" -eq 0 ]]; then
   88	  command -v codex >/dev/null || { echo "ERROR: codex CLI not found" >&2; exit 1; }
   89	  run codex plugin add "$PLUGIN@$MARKETPLACE"
   90	fi
   91	
   92	command -v rsync >/dev/null || { echo "ERROR: rsync not found" >&2; exit 1; }
   93	run mkdir -p "$CACHE_DIR"
   94	run rsync -aL --delete "$SOURCE/" "$CACHE_DIR/"
   95	run mkdir -p "$CURRENT_DIR"
   96	run rsync -aL --delete "$SOURCE/" "$CURRENT_DIR/"
   97	
   98	if [[ "$DRY_RUN" -eq 1 ]]; then
   99	  echo "Dry run complete."
  100	  exit 0
  101	fi
  102	
  103	python3 - "$CACHE_DIR" "$CURRENT_DIR" <<'PY'
  104	import json
  105	import shlex
  106	import sys
  107	from pathlib import Path
  108	
  109	cache = Path(sys.argv[1]).resolve()
  110	current = Path(sys.argv[2]).resolve()
  111	hook_runner = shlex.quote(str(current / "hooks" / "run-hook.cmd"))
  112	
  113	for root in (cache, current):
  114	    hooks_json = root / "hooks" / "hooks.json"
  115	    config = json.loads(hooks_json.read_text(encoding="utf-8"))
  116	    for event_entries in config.get("hooks", {}).values():
  117	        for entry in event_entries:
  118	            for hook in entry.get("hooks", []):
  119	                command = hook.get("command")
  120	                if isinstance(command, str):
  121	                    hook["command"] = command.replace(
  122	                        '"${CLAUDE_PLUGIN_ROOT:-.}/hooks/run-hook.cmd"',
  123	                        hook_runner,
  124	                    )
  125	
  126	    hooks_json.write_text(json.dumps(config, indent=2) + "\n", encoding="utf-8")
  127	PY
  128	
  129	python3 - "$CACHE_DIR" "$CURRENT_DIR" "$PLUGIN" "$VERSION" <<'PY'
  130	import json
  131	import sys
  132	from pathlib import Path
  133	
  134	cache = Path(sys.argv[1])
  135	current = Path(sys.argv[2])
  136	plugin = sys.argv[3]
  137	expected = sys.argv[4]
  138	
  139	for root in (cache, current):
  140	    manifest = root / ".codex-plugin" / "plugin.json"
  141	    data = json.loads(manifest.read_text(encoding="utf-8"))
  142	    if data.get("name") != plugin:
  143	        raise SystemExit(f"{root} manifest name mismatch: {data.get('name')!r} != {plugin!r}")
  144	    if data.get("version") != expected:
  145	        raise SystemExit(f"{root} manifest version mismatch: {data.get('version')!r} != {expected!r}")
  146	    for rel in (
  147	        "skills/using-superstar/SKILL.md",
  148	        "skills/project-setup/SKILL.md",
  149	        "skills/using-git-worktrees/SKILL.md",
  150	        "hooks/run-hook.cmd",
  151	        "hooks/agent-finished",
  152	        "tools/tasktool/notify.py",
  153	        "assets",
  154	    ):
  155	        if not (root / rel).exists():
  156	            raise SystemExit(f"{root} missing required payload: {rel}")
  157	    for rel in ("skills", "hooks", "tools", "assets"):
  158	        if (root / rel).is_symlink():
  159	            raise SystemExit(f"{root} {rel} payload is still a symlink; expected materialized path")
  160	print(f"PASS: {plugin} cache is materialized at {cache}")
  161	print(f"PASS: {plugin} current entrypoint is materialized at {current}")
  162	PY
  163	
  164	EXTERNAL_REVIEWER_SOURCE_ROOT="$CURRENT_DIR" \
  165	  "$CURRENT_DIR/skills/external-review/install.sh"
