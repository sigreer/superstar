F6. Severity: important — Task 10 introduces a test dependency on `tasktool list --all`, but that is neither present in the current CLI nor listed as a P5.S1 precondition. The only `--all` in the spec is for `tasktool worktree list [--all]`, not top-level `tasktool list` (`docs/specs/2026-05-21-P5-tasktool-worktree-lifecycle-design.md:177-184`). Current `tasktool list` accepts `--phase`, `--status`, `--kind`, `--open`, and `--format`, but no `--all` (`tools/tasktool/cli.py:211-216`). The planned ad-hoc tests call `_tasktool(repo, "list", "--all")` twice (`docs/plans/2026-05-21-P5-S2-prune-and-repair.md:1261-1263`, `:1290-1292`), so Task 10 will fail even after S1 unless S1 unexpectedly changes the top-level list command. Use `tasktool list --kind cross`, `tasktool list --format json --kind cross`, or add `list --all` to the explicit S1 contract.

F7. Severity: minor — The final pre-commit “verification” is not a real gate because it always exits successfully. Task 13 runs `pre-commit run --all-files 2>/dev/null || true` (`docs/plans/2026-05-21-P5-S2-prune-and-repair.md:1530-1533`), which masks both “pre-commit not installed” and actual hook failures. If this is meant to be optional, split detection from execution; if configured, failures should block or at least be reported.
