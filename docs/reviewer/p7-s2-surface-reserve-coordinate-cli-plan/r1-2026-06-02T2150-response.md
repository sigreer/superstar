The plan introduces idempotency as `any(r.resource == resource and r.value == value for r in item.reservations)` at `docs/plans/2026-06-02-P7-S2-surface-reserve-coordinate-cli.md:606-608`, while the spec treats scope as part of reservation identity and ledger dedupe at `docs/specs/2026-06-02-P7-integration-surface-parallel-safety-design.md:170-177`. Add a test for same slice, same `resource:value`, different `scope`, and make self-dedupe include `scope` or explicitly upgrade the reservation.

The dedupe appears at `docs/plans/2026-06-02-P7-S2-surface-reserve-coordinate-cli.md:601-608`, but the replacement block at `docs/plans/2026-06-02-P7-S2-surface-reserve-coordinate-cli.md:875-903` omits it.
