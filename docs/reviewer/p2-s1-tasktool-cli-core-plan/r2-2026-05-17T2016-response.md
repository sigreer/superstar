The plan now checks only `^\d{4}-\d{2}-\d{2}$` (`docs/plans/2026-05-17-p2-s1-tasktool-cli-core.md:870`, `879-882`), so values like `2026-99-99` or `2026-02-31` pass validation and can still be compared lexically. F7. Severity: blocking — The new short-ID fix breaks Task 8’s executable ordering.

Task 8 then tells the worker to run `test_commands` green before committing (`docs/plans/...:1587-1589`), and the existing `test_create_task` path will hit `NameError`. Move `_resolve_id()` into Task 8 before `cmd_create_task()`, or keep Task 8’s original fully-qualified lookup and only switch to `_resolve_id()` in Task 9.

- I’m treating each task’s green gate as mandatory before its commit, so cross-task forward references are blocking.

3. Suggested document edits
