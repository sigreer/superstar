# Review: docs/plans/2026-05-20-X11-global-external-reviewer-bridge.md

## 1. Findings

**F1 — Compatibility-shim delegation test will fail due to PATH stripping (Task 3 Step 1). Severity: blocking**

`test_compat_shim_delegates_to_global_external_reviewer` sets `env["PATH"] = str(bin_dir)` — i.e. the temp bin only. The fake `external-reviewer` script has `#!/usr/bin/env bash`. When the compat shim runs `os.execvp(target, ...)`, the new process inherits that PATH=bin_dir. `/usr/bin/env` then resolves `bash` via the inherited PATH and fails (no `bash` in `tmp/bin`).

Recommend: preserve the system PATH and prepend the tmp bin in this single test, e.g.

```python
env["PATH"] = f"{path}:{env.get('PATH','')}"
```

…and update `run_shim` to accept that, or pass the system PATH explicitly. The other two compat-shim tests are unaffected (they exit before `execvp`).

**F2 — Installer's "already installed" early diagnostic prints but does not return, so re-runs work but the message is misleading. Severity: minor**

In `install.sh` Step 1, the branch:

```bash
if grep -q "external-reviewer shim" "$TARGET" 2>/dev/null; then
  echo "external-reviewer shim already installed. Updating source path..."
else
  echo "ERROR: ... not an external-reviewer shim ..." >&2
  exit 1
fi
```

…runs only when `-f "$TARGET" && FORCE != "--force"`. The "Updating source path..." path then falls through to the `cat > "$TARGET" <<EOF` block, which rewrites the file. That's correct behavior, but if a future maintainer adds an `exit 0` here they'll skip the rewrite. Not an issue today; worth a one-line comment that the diagnostic intentionally falls through.

**F3 — `Pointing at` self-test runs the bridge with `--help` but the plan never asserts that `scripts/external-reviewer.py` supports `--help`. Severity: minor**

`install.sh` ends with `"$TARGET" --help >/dev/null` and the pytest checks `"review" in result.stdout`. If the existing bridge's `--help` output doesn't contain the literal word "review", the test fails. Quick sanity grep before implementing would close this risk; add a verification line in the plan (`python3 skills/external-review/scripts/external-reviewer.py --help` to confirm).

**F4 — Task 4 Step 7 commit instructions are self-contradicting. Severity: minor**

The commit command stages it but then the trailing note says "If unchanged, omit it from git add". Pick one: either expect a change (and say what), or remove it from the Files list and `git add`.
